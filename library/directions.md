# Direction worlds
Manestream Build Library, checked 2 Oct 2026. Pick one per project (rotate; never reuse the last project's world and pairing). Fonts are Google Fonts unless marked Fontshare (Indian Type Foundry, free for commercial use). Dials are layout variance, motion, density (1 to 10).

For Orion (PEB manufacturer): the closest world is **Industrial Precision**. Orion already ships a navy / rust / apricot theme with Bricolage Grotesque, Hanken Grotesk and JetBrains Mono, so treat these worlds as a reference for review, not a reason to restart the design.

## Editorial Luxury
- Fits: real estate, jewellery and fashion, hospitality, architecture
- Type pairings: Cormorant Garamond + Manrope; Bodoni Moda + Hanken Grotesk; Gambetta + Switzer (Fontshare); Fraunces + Figtree
- Palettes:
  - Warm paper #F4EFE7, ink #1C1A17, stone #8C8378, bronze accent #A06B3B
  - Ivory #F7F3EC, deep green ink #1F2A24, sage #8A9A86, brass accent #B08A4E
  - Limestone #EFEAE2, charcoal #22201D, taupe #9A8F84, oxblood accent #7A2E2A
- Layout: wide margins, asymmetric image and text, full-bleed chapters, small captions.
- Motion: slow (800 to 1200ms) image unmasking and restrained parallax under 8%. No bounce.
- Default dials: 6, 4, 3

## Swiss Precision
- Fits: agency, architecture, consulting, SaaS
- Type pairings: Schibsted Grotesk throughout; Archivo (wide and condensed widths); Familjen Grotesk + IBM Plex Mono for data
- Palettes:
  - Off-white #FAFAF7, ink #121212, signal red #E63312
  - Paper #F5F5F0, ink #151515, cobalt #2D5BFF
  - Bone #F2F0EB, graphite #1B1B1B, safety orange #FF5B1F
- Layout: strict 12-column grid, oversized flush-left type, ragged right, rules that organise real content.
- Motion: snappy (200 to 300ms) line-by-line text slides and hard cuts.
- Default dials: 7, 4, 5

## Retro-Tech Terminal
- Fits: developer tools, cybersecurity, data products
- Type pairings: JetBrains Mono + IBM Plex Sans; Geist Mono + Geist; Space Mono + Work Sans
- Palettes:
  - Green-black #0C0F0C, phosphor accent #7CFF6B used sparingly, grey #9AA19A

- Type pairings: Rozha One + Mukta (Devanagari + Latin); Martel + Mukta; Tiro Devanagari Hindi + Hind
- Palettes:
  - Haldi #E3A21A, sindoor #B3261E, ivory #F7F1E3, kohl ink #1E1A17
  - Indigo #23395B, ivory #F6F1E7, marigold #F2A541, henna accent #8A3B12

## Hero architectures
- Type-led asymmetric with one bleeding image
- Full-bleed video, headline bottom-left
- Split: text left, media bleeding right
- Real product screenshot as proof
- Pinned image sequence that advances on scroll
- 3D or shader backdrop behind type
- Editorial collage of three photos
- Single object on a plain field
- Location-first map opener
- Big real metric as the statement
